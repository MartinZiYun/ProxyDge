## English

### ProxyDge v0.3.3 — i18n: validation errors, warning labels & startup messages

Patch release translating user-facing messages that were previously hardcoded English. Config keys and enum values stay in English; only the surrounding descriptive text is translated.

#### What's new

- **ConfigError type**: `Validate()` now returns `*ConfigError{Key, Args, msg}` instead of plain `fmt.Errorf`. `main.go` checks `errors.As(err, &ce)` and translates via the i18n catalog; non-ConfigError errors (file I/O, YAML parsing) fall back to English.
- **WARNING/NOTICE labels**: the `WARNING:` and `NOTICE:` prefixes are now translated via `label.warning` / `label.notice` i18n keys.
- **Startup errors**: `unknown command`, `Run 'proxydge help'`, `init: already exists`, and `wrote sample config` are now translated.
- **21 new i18n keys** across all three locales (en, zh-CN, zh-TW): 2 labels + 4 startup errors + 16 validation errors.

#### What's NOT translated

- Config key names: `policy`, `detect-timeout`, `trusted-networks`, `untrusted-proxy-action`, etc.
- Enum values: `use|require|reject`, `text|json`, `tcp|udp`, etc.
- Program name: `proxydge`
- Version banner: `version.String()` output (technical diagnostic, stable for log parsing)
- `fileSource.Apply()` / `envSource` parse errors (10 + 5 sites — future task)

**Full Changelog**: https://github.com/MartinZiYun/ProxyDge/compare/v0.3.2...v0.3.3

## 简体中文

### ProxyDge v0.3.3 — i18n：校验错误、警告标签与启动消息翻译

补丁版本：翻译之前硬编码的英文用户面向消息。配置 key 名和枚举值保持英文，只翻译描述文字。

#### 新功能

- **ConfigError 类型**：`Validate()` 返回 `*ConfigError{Key, Args, msg}` 而非 `fmt.Errorf`。`main.go` 通过 `errors.As(err, &ce)` 检查并翻译；非 ConfigError 错误（文件 I/O、YAML 解析）回退英文。
- **WARNING/NOTICE 标签**：`WARNING:` 和 `NOTICE:` 前缀通过 `label.warning` / `label.notice` i18n key 翻译。
- **启动错误**：`unknown command`、`Run 'proxydge help'`、`init: already exists`、`wrote sample config` 均已翻译。
- **21 个新 i18n key**，覆盖三种语言（en、zh-CN、zh-TW）：2 标签 + 4 启动错误 + 16 校验错误。

#### 不翻译的内容

- 配置 key 名：`policy`、`detect-timeout`、`trusted-networks`、`untrusted-proxy-action` 等
- 枚举值：`use|require|reject`、`text|json`、`tcp|udp` 等
- 程序名：`proxydge`
- 版本信息：`version.String()` 输出（技术诊断信息，保持稳定供日志解析）
- `fileSource.Apply()` / `envSource` 解析错误（10 + 5 处 — 后续任务）

**完整变更**：https://github.com/MartinZiYun/ProxyDge/compare/v0.3.2...v0.3.3
