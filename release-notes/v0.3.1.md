## English

### ProxyDge v0.3.1 — Config migration fixes

Patch release fixing two config issues discovered after v0.3.0: bare IP rejection in `trusted-networks` validation, and broken v1→v2 config migration.

> **If you upgraded to v0.3.0 and your config was auto-migrated**, the migrated file may have lost v1 flat field values (e.g. `detect-timeout`, `idle-timeout`) — they were written as unknown fields at the bottom instead of being mapped to v2 nested locations. Re-migrate from your `.bak` backup, or manually move flat fields into `tcp:`/`udp:` sections.

#### Fixes

- **Bare IP in `trusted-networks`**: config validation rejected bare IPs like `10.0.0.1` with "invalid CIDR address". The trust checker already supported bare IPs (auto-converts to `/32` or `/128`), but the config validation layer used `net.ParseCIDR` only. Now both layers accept CIDR and bare IP.
- **v1→v2 config migration**: three bugs in `generateMigratedConfig`:
  1. **V1 flat fields not mapped**: flat fields (`detect-timeout`, `idle-timeout`, `max-sessions`, `max-datagram-size`, `udp-output`) were treated as unknown fields and preserved verbatim at the bottom of the migrated file, while the corresponding v2 nested fields got default values. Now they are mapped to their v2 locations (`tcp.detect-timeout`, `udp.idle-timeout`, `udp.max-sessions`, `udp.max-datagram-size`, `udp.header-mode`).
  2. **In-memory values lost**: after migration wrote the v2 file, the in-memory `Config` still reflected the old v1 parse (flat fields not captured by `yamlFields`). Now the file is re-read after migration so in-memory values match the migrated file.
  3. **Migration output didn't match `-init` template**: field order, section headers, and comments diverged from `proxydge -init` output. Now the migrated file mirrors the template structure (`protocol` in General section, `# ── General` / `# ── Logging` headers, trust comments with CIDR+bare IP examples, etc.).

#### What changed

- `internal/config/config.go`: `Validate()` accepts bare IP; `generateMigratedConfig` maps v1 flat fields from `raw`; `knownConfigKeys` includes v1 flat field names; `fileSource.Apply` re-reads file after migration; migration output matches template.
- `internal/config/config_test.go`: `TestValidateBareIPTrustedNetworks` added; `TestValidateBadTrustedNetworkCIDR` uses `defaultsSource`.
- `internal/config/migration_test.go`: `TestMigrationV1FlatFields` added (file output + in-memory values + no leaked flat fields).
- `internal/config/log_test.go`, `provenance_test.go`: version bumped to 2 in test configs to avoid migration side effects in non-migration tests.

**Full Changelog**: https://github.com/MartinZiYun/ProxyDge/compare/v0.3.0...v0.3.1

## 简体中文

### ProxyDge v0.3.1 — 配置迁移修复

修复 v0.3.0 发布后发现的两个配置问题：`trusted-networks` 校验拒绝裸 IP，以及 v1→v2 配置迁移功能损坏。

> **如果您升级到 v0.3.0 且配置被自动迁移过**，迁移后的文件可能丢失了 v1 扁平字段值（如 `detect-timeout`、`idle-timeout`）— 它们被当作未知字段写在了文件底部，而非映射到 v2 嵌套位置。请从 `.bak` 备份重新迁移，或手动将扁平字段移入 `tcp:`/`udp:` 段。

#### 修复

- **`trusted-networks` 裸 IP**：配置校验拒绝裸 IP（如 `10.0.0.1`），报 "invalid CIDR address"。信任检查器本已支持裸 IP（自动转为 `/32` 或 `/128`），但配置校验层只用了 `net.ParseCIDR`。现两层均接受 CIDR 和裸 IP。
- **v1→v2 配置迁移**：`generateMigratedConfig` 三个 bug：
  1. **v1 扁平字段未映射**：扁平字段（`detect-timeout`、`idle-timeout`、`max-sessions`、`max-datagram-size`、`udp-output`）被当作未知字段原样保留在迁移文件底部，而对应的 v2 嵌套字段用默认值。现已映射到 v2 位置（`tcp.detect-timeout`、`udp.idle-timeout`、`udp.max-sessions`、`udp.max-datagram-size`、`udp.header-mode`）。
  2. **内存值丢失**：迁移写入 v2 文件后，内存 `Config` 仍反映旧的 v1 解析（扁平字段未被 `yamlFields` 捕获）。现迁移后重读文件，内存值与迁移文件一致。
  3. **迁移输出不匹配 `-init` 模板**：字段顺序、区块头和注释与 `proxydge -init` 输出不一致。现迁移文件与模板结构一致（`protocol` 在 General 区、`# ── General` / `# ── Logging` 区块头、trust 注释含 CIDR+裸 IP 示例等）。

#### 变更内容

- `internal/config/config.go`：`Validate()` 接受裸 IP；`generateMigratedConfig` 从 `raw` 映射 v1 扁平字段；`knownConfigKeys` 包含 v1 扁平字段名；`fileSource.Apply` 迁移后重读文件；迁移输出匹配模板。
- `internal/config/config_test.go`：新增 `TestValidateBareIPTrustedNetworks`；`TestValidateBadTrustedNetworkCIDR` 改用 `defaultsSource`。
- `internal/config/migration_test.go`：新增 `TestMigrationV1FlatFields`（文件输出 + 内存值 + 无泄漏扁平字段）。
- `internal/config/log_test.go`、`provenance_test.go`：测试配置版本改为 2，避免非迁移测试受迁移副作用影响。

**完整变更**：https://github.com/MartinZiYun/ProxyDge/compare/v0.3.0...v0.3.1
