### ProxyDge v0.2.0 — Source trust control, i18n & config auto-migration

*2026-08-21*

> ⚠️ **Deprecated — do not download.** v0.3.0 introduces a major architecture overhaul (UDP gateway, three-layer transport abstraction, nested `tcp:`/`udp:` config sections, config format v2). Old config files auto-migrate to v2 on first launch of v0.3.0. **Please use v0.3.0 instead.**

This release introduces source trust control (preventing PROXY header spoofing), multi-language CLI output, and automatic config-file migration.

> **Please use this release.** v0.1.0 carried release-pipeline teething issues (GoReleaser `archives` deprecation, `-trimpath` left in ldflags, CI `workflow_call` brace conflicts). **Do not download v0.1.0** — upgrade to v0.2.0.

#### Highlights

- **Source trust control**: only configured trusted IP networks may send PROXY headers, preventing address spoofing. Security-critical: the trust check always uses the TCP socket's real `RemoteAddr()`, never the address claimed in the header — an attacker cannot bypass it by forging a trusted IP inside the header.
- **Multi-language**: `en`, `zh-CN`, `zh-TW`; locale files embedded via `go:embed`, no external dependencies
- **Config auto-migration**: old config files auto-upgrade on startup — backs up the original to `.bak`, preserves unknown fields verbatim, prints a `NOTICE`

#### New Configuration (trust control)

```yaml
trusted-networks:
  - "10.0.0.0/8"
untrusted-proxy-action: "reject"   # reject (default) | strip
```

Behavior when a PROXY header is present and the source IP is **not** trusted:

| `untrusted-proxy-action` | Result |
|---|---|
| `reject` (default) | close the connection immediately |
| `strip` | strip the header, re-normalize as a direct connection using the real peer address |

Startup warnings fire when `trusted-networks` is empty (all sources trusted → spoofing risk) or when `untrusted-proxy-action=strip` (untrusted sources can still connect).

#### Features

- **Source trust control**
  - `internal/gateway`: new `TrustChecker` + `UntrustedAction` type
  - Gateway integrates the source trust check into the accept path
  - Config gains trust-control fields + security warnings
  - `main.go` wires the trust checker and prints startup security warnings
- **Multi-language (i18n)**
  - CLI supports `en` / `zh-CN`, locale YAML embedded via `go:embed`; respects the `--lang` flag, `PROXYDGE_LANG` env, and the system locale
  - Added `zh-TW` (Traditional Chinese)
- **Config**
  - Auto-migrate old config files on startup, preserving unknown fields verbatim
  - Grouped config display with simplified `file` source labels
- `proxydge init` now refuses to overwrite an existing config (use `-force`)
- `io.Copy` emits debug-level logs

#### Fixes

- `fix(i18n)`: the `help` command now parses the `-lang` flag

#### Chores

- Dev artifacts renamed to `proxydge-dev-<build>-<os>-<arch>`

#### Docs

- Source trust control: design spec, implementation plan, and final report added under `docs/`

### ProxyDge v0.2.0 — 来源信任控制、多语言与配置自动迁移

*2026-08-21*

> ⚠️ **已弃用 — 请勿下载。** v0.3.0 引入了重大架构变更（UDP 网关、三层传输抽象、嵌套 `tcp:`/`udp:` 配置段、配置格式 v2）。旧配置文件在 v0.3.0 首次启动时自动迁移到 v2。**请使用 v0.3.0。**

本版本引入来源信任控制（防止 PROXY header 伪造）、CLI 多语言输出与配置文件自动迁移。

> **请使用本版本。** v0.1.0 存在发布流水线的磨合问题（GoReleaser `archives` deprecation、ldflags 残留 `-trimpath`、CI `workflow_call` 花括号冲突）。**请勿下载 v0.1.0** — 请升级到 v0.2.0。

#### 亮点

- **来源信任控制**：只有配置的可信 IP 网段才能发送 PROXY header，防止地址伪造。安全关键：信任检查始终使用 TCP 套接字的真实 `RemoteAddr()`，绝不使用 header 里声称的地址 —— 攻击者无法通过在 header 中伪造可信 IP 绕过检查。
- **多语言**：`en`、`zh-CN`、`zh-TW`；语言文件 `go:embed` 编译进二进制，无外部依赖
- **配置自动迁移**：启动时自动升级旧配置文件 —— 备份原文件到 `.bak`，未知字段原样保留，打印 `NOTICE`

#### 新增配置（信任控制）

```yaml
trusted-networks:
  - "10.0.0.0/8"
untrusted-proxy-action: "reject"   # reject（默认） | strip
```

当连接带 PROXY header 且来源 IP **不在可信网段**时的行为：

| `untrusted-proxy-action` | 结果 |
|---|---|
| `reject`（默认） | 直接关闭连接 |
| `strip` | 剥离 header，用真实 peer 地址重新归一化为直连 |

`trusted-networks` 为空（所有来源被信任 → 有伪造风险）或 `untrusted-proxy-action=strip`（非可信来源仍可连接）时，启动会打印安全警告。

#### 功能

- **来源信任控制**
  - `internal/gateway`：新增 `TrustChecker` + `UntrustedAction` 类型
  - 网关在监听路径集成来源信任检查
  - 配置新增信任控制字段与安全警告
  - `main.go` 接线信任检查器并打印启动安全警告
- **多语言（i18n）**
  - CLI 支持 `en` / `zh-CN`，语言文件 YAML 经 `go:embed` 嵌入；支持 `--lang` flag、`PROXYDGE_LANG` 环境变量与系统 locale
  - 新增 `zh-TW`（繁體中文）
- **配置**
  - 启动时自动迁移旧配置文件，未知字段原样保留
  - 配置打印分组显示，简化 `file` 来源标签
- `proxydge init` 拒绝覆盖已有配置（需 `-force`）
- `io.Copy` 输出 debug 级别日志

#### 修复

- `fix(i18n)`：`help` 命令现在能解析 `-lang` flag

#### 杂项

- dev 产物改名为 `proxydge-dev-<build>-<os>-<arch>`

#### 文档

- 来源信任控制：设计文档、实现计划与最终报告已加入 `docs/`
