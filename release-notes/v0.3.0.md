## English

### ProxyDge v0.3.0 — UDP gateway, three-layer transport architecture & IPv4/IPv6 dual-stack

This release adds a full UDP PROXY Protocol gateway alongside the existing TCP gateway, with a redesigned three-layer transport architecture, IPv4/IPv6 dual-stack support, and config format v2 (nested `tcp:`/`udp:` sections).

#### Highlights

- **UDP gateway**: complete datagram/session model — per-session connected upstream sockets, idle timeout, max session limit, configurable PROXY header emission mode (`every_datagram` / `first_datagram`). UDP does NOT adapt into TCP's stream abstraction; it has its own `DatagramReader`/`DatagramWriter` and session lifecycle.
- **Three-layer transport architecture**: `internal/protocol` (enum) → `internal/transport` (cross-transport interfaces: `AddrConn`, `Conn`, `CloseWriter`, `RemoteIP`) → `internal/tcp` + `internal/udp` (transport-specific implementations). TCP's `pipeStream()` and `CloseWriter` are NOT used by UDP.
- **IPv4/IPv6 dual-stack**: full IPv6 support. UDP session keys include IPv6 zone identifiers (`fe80::1%eth0` ≠ `fe80::1%eth1`). Trust networks support IPv6 CIDR and bare IPv6 addresses. Note: PROXY Protocol v2 wire format does not support zone — zones are preserved locally for routing but not transmitted downstream.
- **Shared decision logic**: `Decide()` (trust + policy) extracted from the TCP gateway into a transport-agnostic function reused by both TCP and UDP.
- **Config format v2**: nested `tcp:`/`udp:` sections (matching `log:`). Auto-migration from v1. Protocol-specific env/flags use `TCP_`/`UDP_` prefixes.
- **Bare IP trust**: `trusted-networks` accepts bare IPs (`10.0.0.1` → `/32`, `2001:db8::1` → `/128`) in addition to CIDR.

> ⚠️ **Known issue — fixed in v0.3.1.** The v1→v2 auto-migration in this release has bugs: v1 flat fields (`detect-timeout`, `idle-timeout`, `max-sessions`, `max-datagram-size`, `udp-output`) are not mapped to their v2 nested locations — they appear as unknown fields at the bottom of the migrated file while the nested fields get default values. Additionally, config validation rejects bare IPs in `trusted-networks`. If you encounter these issues, upgrade to v0.3.1 and re-migrate from your `.bak` backup.

#### Security invariants (UDP)

1. **Resource ordering**: `Decide()` runs BEFORE session creation — rejected sources consume zero resources (no socket, no goroutine, no session slot)
2. **Header ownership**: persisted session metadata is deep-copied (`cloneHeader`) — no references to the reusable `ReadFromUDP` packet buffer
3. **inputSource trust gating**: PROXY header metadata persisted as session state ONLY after trust check passes — untrusted metadata never enters session state
4. **No state inheritance on recreation**: `expire()` clears state + removes from map atomically (`sync.Once`) — prevents source port reuse attacks

#### New configuration

```yaml
version: 2  # do NOT change; used for auto-migration

# ── General ───────────────────────────────────────────────────────────
protocol: "tcp"                      # tcp (default) | udp
listen: ":9000"
upstream: "127.0.0.1:9001"
policy: "use"

trusted-networks:
  - "10.0.0.0/8"           # IPv4 CIDR
  - "2001:db8::/32"        # IPv6 CIDR
  - "10.0.0.1"             # bare IP → /32
untrusted-proxy-action: "reject"

# ── TCP ──────────────────────────────────────────────────────────────
tcp:
  detect-timeout: "1s"

# ── UDP ──────────────────────────────────────────────────────────────
udp:
  idle-timeout: "30s"
  max-sessions: 1024
  max-datagram-size: 65535          # 0=unlimited
  header-mode: every_datagram       # every_datagram (default) | first_datagram
```

New env vars: `PROXYDGE_PROTOCOL`, `PROXYDGE_TCP_DETECT_TIMEOUT`, `PROXYDGE_UDP_IDLE_TIMEOUT`, `PROXYDGE_UDP_MAX_SESSIONS`, `PROXYDGE_UDP_MAX_DATAGRAM_SIZE`, `PROXYDGE_UDP_HEADER_MODE`.

New flags: `-protocol`, `-tcp-detect-timeout`, `-udp-idle-timeout`, `-udp-max-sessions`, `-udp-max-datagram-size`, `-udp-header-mode`.

#### Architecture changes

```
internal/
  protocol/     ← Protocol enum (tcp/udp)
  transport/    ← AddrConn, Conn, CloseWriter, RemoteIP (cross-transport)
  tcp/          ← TCP-specific: Conn (stream + half-close), Listener, Dialer
  udp/          ← UDP-specific: Gateway, Session, SessionManager (datagram model) ← NEW
  gateway/      ← TCP gateway + shared Decide() + pipeStream()
  proxyproto/   ← Header, Source, FamilyUDP4/6, DatagramReader/Writer ← NEW
    goproxyproto/
      datagram.go  ← UDP datagram adapter (manual v2 parsing, no bufio.Reader) ← NEW
```

#### What's new

- **UDP gateway** (`internal/udp/`): `UDPGateway`, `UDPSession` (lifecycle + reader goroutine + idle timer), `UDPSessionManager` (sync.Map + atomic count + max sessions + WaitGroup graceful shutdown)
- **proxyproto extensions**: `FamilyUDP4`/`FamilyUDP6`, `HeaderFromAddrs(src, dst)`, `DatagramReader`/`DatagramWriter` interfaces
- **goproxyproto datagram adapter**: `ParseDatagram` (manual v2 header parsing from raw bytes — no `bufio.Reader`), `FormatDatagram` (header + payload → `[]byte`)
- **transport extensions**: `CloseWriter` (optional capability, not embedded in `Conn`), `RemoteIP` (handles `*net.UDPAddr`)
- **gateway extraction**: `Decide()` exported for UDP reuse, `pipeStream()` extracted as TCP-only
- **trust bare IP**: `NewTrustChecker` accepts bare IPs, auto-converts to `/32` or `/128`
- **config v2**: nested `tcp:`/`udp:` sections, `upstream` default (`127.0.0.1:9001`), `max-datagram-size: 0` = unlimited

#### Tests

- 19 UDP gateway tests (6 input×output combinations, 4 security invariants, 4 edge cases, 4 policy combinations, IPv6 integration)
- 9 datagram adapter unit tests (direct/v2-UDP4/TCP4/UDP6/malformed/bad-version/bad-command/unknown-family/TLV-skip)
- 5 trust checker tests (IPv6 CIDR, link-local, bare IPv4/IPv6, mixed)
- 3 IPv6 integration tests (`::1` loopback: direct→every, every→every, direct→first)
- 2 UDP benchmarks (single-socket throughput, concurrent)
- All existing TCP tests pass unchanged

## 简体中文

### ProxyDge v0.3.0 — UDP 网关、三层传输架构与 IPv4/IPv6 双栈

本版本在现有 TCP 网关基础上新增完整的 UDP PROXY Protocol 网关，重新设计三层传输架构，支持 IPv4/IPv6 双栈，并引入配置格式 v2（嵌套 `tcp:`/`udp:` 段）。

#### 亮点

- **UDP 网关**：完整的数据报/session 模型 — 每 session 独立上游 socket、空闲超时、最大 session 限制、可配置 PROXY header 发射模式（`every_datagram` / `first_datagram`）。UDP 不适配进 TCP 的流抽象；拥有独立的 `DatagramReader`/`DatagramWriter` 和 session 生命周期。
- **三层传输架构**：`internal/protocol`（枚举）→ `internal/transport`（跨传输接口：`AddrConn`、`Conn`、`CloseWriter`、`RemoteIP`）→ `internal/tcp` + `internal/udp`（传输专用实现）。TCP 的 `pipeStream()` 和 `CloseWriter` 不被 UDP 使用。
- **IPv4/IPv6 双栈**：完整 IPv6 支持。UDP session key 包含 IPv6 zone 标识符（`fe80::1%eth0` ≠ `fe80::1%eth1`）。信任网络支持 IPv6 CIDR 和裸 IPv6 地址。注意：PROXY Protocol v2 wire 格式不支持 zone — zone 在本地用于路由但不传输到下游。
- **共享决策逻辑**：`Decide()`（信任 + 策略）从 TCP 网关提取为传输无关函数，TCP 和 UDP 共享。
- **配置格式 v2**：嵌套 `tcp:`/`udp:` 段（与 `log:` 一致）。从 v1 自动迁移。协议专用 env/flag 使用 `TCP_`/`UDP_` 前缀。
- **裸 IP 信任**：`trusted-networks` 接受裸 IP（`10.0.0.1` → `/32`，`2001:db8::1` → `/128`），除 CIDR 外。

> ⚠️ **已知问题 — v0.3.1 已修复。** 本版本的 v1→v2 自动迁移存在 bug：v1 扁平字段（`detect-timeout`、`idle-timeout`、`max-sessions`、`max-datagram-size`、`udp-output`）未映射到 v2 嵌套位置 — 它们作为未知字段出现在迁移文件底部，而嵌套字段使用默认值。此外，配置校验拒绝 `trusted-networks` 中的裸 IP。如遇此问题，请升级到 v0.3.1 并从 `.bak` 备份重新迁移。

#### 安全不变量（UDP）

1. **资源排序**：`Decide()` 在 session 创建之前执行 — 被拒绝的来源消耗零资源（无 socket、无 goroutine、无 session 槽位）
2. **Header 所有权**：持久化的 session 元数据深拷贝（`cloneHeader`）— 不引用可复用的 `ReadFromUDP` packet buffer
3. **inputSource 信任门控**：PROXY header 元数据仅在信任检查通过后才作为 session 状态持久化 — 不可信元数据永不进入 session 状态
4. **重建无继承**：`expire()` 原子清空状态 + 从 map 移除（`sync.Once`）— 防止源端口重用攻击

#### 架构变更

```
internal/
  protocol/     ← Protocol 枚举 (tcp/udp)
  transport/    ← AddrConn, Conn, CloseWriter, RemoteIP（跨传输）
  tcp/          ← TCP 专用：Conn (流 + 半关闭), Listener, Dialer
  udp/          ← UDP 专用：Gateway, Session, SessionManager (数据报模型) ← 新增
  gateway/      ← TCP 网关 + 共享 Decide() + pipeStream()
  proxyproto/   ← Header, Source, FamilyUDP4/6, DatagramReader/Writer ← 新增
    goproxyproto/
      datagram.go  ← UDP 数据报适配器（手动解析 v2，不用 bufio.Reader）← 新增
```

#### 新增内容

- **UDP 网关**（`internal/udp/`）：`UDPGateway`、`UDPSession`（生命周期 + reader goroutine + idle timer）、`UDPSessionManager`（sync.Map + 原子计数 + max sessions + WaitGroup 优雅关闭）
- **proxyproto 扩展**：`FamilyUDP4`/`FamilyUDP6`、`HeaderFromAddrs(src, dst)`、`DatagramReader`/`DatagramWriter` 接口
- **goproxyproto 数据报适配器**：`ParseDatagram`（从原始字节手动解析 v2 header — 不用 `bufio.Reader`）、`FormatDatagram`（header + payload → `[]byte`）
- **transport 扩展**：`CloseWriter`（可选能力，不嵌入 `Conn`）、`RemoteIP`（处理 `*net.UDPAddr`）
- **gateway 提取**：`Decide()` 导出供 UDP 复用，`pipeStream()` 提取为 TCP 专用
- **信任裸 IP**：`NewTrustChecker` 接受裸 IP，自动转为 `/32` 或 `/128`
- **配置 v2**：嵌套 `tcp:`/`udp:` 段、`upstream` 默认值（`127.0.0.1:9001`）、`max-datagram-size: 0` = 无限制
